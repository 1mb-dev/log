Version 2.0.3 of a database driver is still downloadable today. The repo it came from has no version 2. It hasn't for years.

Running since 2011. One name on almost every commit.

Between 2018 and 2020, four releases went out numbered 2. Nobody meant them. One of them shipped the same day as a version 1 release.

The tags came off. The versions did not.

The fix was a line of text. One entry in the project file marking that whole range retracted, with a reason. Accidental. No major changes or features.

Version 1 kept going. Fifty releases on the same minor number, still arriving.

The record does not take edits. Only additions.
